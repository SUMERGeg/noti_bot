# Карточки и напоминания

Утверждённый объём: название, необязательное описание, несколько времён,
повторение ежедневно, по дням недели или числам месяца. Создание, чтение,
редактирование и удаление в Telegram Mini App. Уведомление содержит название
и кнопку открытия, если заполнено описание. Без истории выполнения.

Решения реализации: FastAPI, SQLAlchemy, PostgreSQL для Render, SQLite только
локально. Часовой пояс у каждой карточки, по умолчанию Europe/Moscow.
Telegram initData проверяется на сервере. Данные изолированы по Telegram ID.
Webhook принимает /start, планировщик вызывается защищённым POST /jobs/tick.
Supabase Free сохраняет данные, cron-job.org Free вызывает tick раз в минуту.
Локально можно включить фоновый планировщик. На бесплатных сервисах возможны
задержки; строгой гарантии времени нет. Пропуски догоняются в течение часа,
старые напоминания не рассылаются пачкой. При неопределённом сетевом результате
Telegram может получить повтор: API не предоставляет ключ идемпотентности.

сетевой границы. На Render приложение ещё не развёрнуто.
